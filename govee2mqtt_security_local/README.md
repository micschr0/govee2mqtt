# govee2mqtt for Home Assistant

Independently maintained [micschr0/govee2mqtt](https://github.com/micschr0/govee2mqtt)
fork of [wez/govee2mqtt](https://github.com/wez/govee2mqtt).
Connects Govee devices through MQTT; LAN preferred, cloud optional, HTTP disabled
by default. This directory contains the authoritative application sources and
builds directly in the Home Assistant store. See [DOCS.md](DOCS.md).
